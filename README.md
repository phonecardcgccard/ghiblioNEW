# GhiblioNEW

> Ghiblio 全新优化版 - AI艺术工具集

本仓库为 Ghiblio.xyz 的全新优化与重构版本，采用纯静态站点架构，注重SEO、用户体验及可维护性。

## 目录结构

```
index.html             // 首页
tools/                 // 各AI工具独立页面
assets/css/style.css   // 全站样式
assets/js/main.js      // 公共脚本
gallery.html           // 画廊页
about.html             // 关于
faq.html               // FAQ
```

## 开发说明

- 使用任何静态网站服务器（如 Netlify、Vercel、GitHub Pages）均可一键部署
- 所有AI调用请封装为API接口，前端 fetch 调用
- 欢迎贡献优化建议和PR
